# Delivery (Part 12) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shipping fee by district zones, couriers + tracking on orders, a print page for the admin, tracking shown to the customer; courier-agnostic.

**Architecture:** Pure rules in `lib/shipping.ts` (tested). One additive migration (two tables, four `orders` columns, a seed zone). `place_order` is NOT replaced: the district is stored by a second update after the order is placed. `placeOrder` computes the fee from the zones on the server and passes it to `planOrder`. Admin gets `/admin/shipping`, a Shipment section on the order page and a print page.

**Tech Stack:** Next.js 16.2 App Router, Supabase (secret-key client), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-09-delivery-design.md`

## Global Constraints
- Next.js 16: read the relevant guide in `node_modules/next/dist/docs/` before writing Next code.
- Money in cents; render with `formatPrice`; the browser never sets a price (server recomputes the fee).
- Customer-facing strings bilingual `<L si en />`; server actions return message **codes**; admin pages English. Sinhala is flagged for owner review.
- Every Server Action starts with `await requireAdmin(...)` (admin) or `requireUser` (customer). Private tables: RLS on, no policies/grants unless stated.
- `place_order` and other existing SQL functions are not replaced. Migration is additive and run by the owner before deploy.
- Run `npx tsc --noEmit && npm run lint && npm test` before every commit; `git add` explicit paths (an untracked `.claude/launch.json` must never be committed). Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Never print or read secrets/.env.

## Review Focus
- A district in two zones, unknown districts, 0 fee, and zones unreadable → default fee (Task 1 tests).
- Tracking URL template without `{number}`, with `http://`, or a tracking number with spaces/`/` must be rejected (Task 1 tests).
- Checkout: unknown/missing district must fail validation; a changed fee returns `price_changed` (Task 3 tests).
- Orders placed before this feature (no district, no courier) must render everywhere without crashing (Tasks 3–5).
- Admin print page and shipment action are admin-only (Tasks 4–5).
